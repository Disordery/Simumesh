# Simumesh
A physics-grounded 2D Wi-Fi propagation &amp; mesh network simulator. A vectorized ray-tracing engine models FSPL, COST231 multi-wall loss, and multipath reflection across 2.4/5/6GHz bands — with SINR mapping, mesh backhaul routing, and simulated-annealing AP placement optimization. Includes a standalone Tkinter CAD floor-plan editor.
